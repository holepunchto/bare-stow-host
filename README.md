# bare-stow-host

Host side of the `bare-stow` (<https://github.com/holepunchto/bare-stow>) lifecycle. Layers readiness, termination, and exit reporting on top of `bare-stow-protocol` (<https://github.com/holepunchto/bare-stow-protocol>). Harnesses generated by `bare-stow` import it to drive the bundles they boot.

```
npm i bare-stow-host
```

## Usage

```js
const Sidecar = require('bare-sidecar')
const { wrap } = require('bare-stow-host')

const sidecar = new Sidecar('/app/out/index.bundle')

const ipc = wrap(sidecar, { kill: () => sidecar.kill('SIGKILL') }) // Any duplex byte stream

sidecar.on('exit', (code, signal) => ipc.exited(code, signal))

await ipc.ready

ipc.write(Buffer.from('hello'))

const code = await ipc.terminate()
```
